# Reference pictures of the original WPF presentations

`CrypWeb.Tests ... snapall` shows each picture here next to the browser rendering of the same view
(`CrypWeb.App/wwwroot/_snap/index.html`). The file name is the view's component type (`FrequencyTest.png`,
`KasiskiTest.jpg`, ...), as listed on the overview page.

The pictures so far come from the plugin documentation (`CrypPlugins/*/DetailedDescription`). Screenshots taken in
the desktop CrypTool 2 on Windows can be added the same way; they are the measure for "renders like the original".

More references: the official CT2 screenshot gallery (https://www.cryptool.org/en/ct2/screenshots) shows many
presentations in the desktop version (Enigma, homophonic substitution analysis, analyzers, Keccak, LFSR, BB84,
...). They are not copied here; compare them in the browser with the rendering of the same template.
